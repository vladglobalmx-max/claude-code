# Plantilla — Accountability Chart

> A diferencia de un organigrama tradicional, el Accountability Chart define **funciones** (no personas) y evalúa el ajuste GWC (Get it, Want it, Capacity) de quien la ocupa hoy.

## Estructura de funciones (ejemplo de nivel dirección)

| Función (sillón) | Resultado que produce | Ocupante actual | GWC (Get it / Want it / Capacity) |
|---|---|---|---|
| Visionario (CEO) | Dirección, relaciones clave, grandes decisiones | | |
| Integrador (COO) | Ejecución del día a día, resuelve conflictos entre áreas | | |
| Comercial | Ingresos y pipeline | | |
| Marketing | Generación de demanda | | |
| Operaciones | Entrega y calidad | | |
| Finanzas | Números y control | | |
| Tecnología | Infraestructura y datos | | |
| RRHH | Personas | | |

- ¿Genuinamente lo quiere hacer (Want it)? Sí/No:
