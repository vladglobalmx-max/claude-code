# Notas de versión — THÖREN Sticker Builder

## v1.0.0

Primera versión comercial de THÖREN Sticker Builder.

**Incluye:**
- Editor de stickers completo: formas, texto, imágenes, capas, alineación, plantillas.
- Grid, Rulers, Smart Guides y snapping asistido.
- Guardado automático + recuperación ante cierre inesperado.
- "Mis proyectos": biblioteca local de proyectos con miniaturas.
- Exportación rápida a PNG (transparente/sólido, 1x-4x) y SVG.
- Exportación profesional para impresión (perfiles Digital PNG / Print PDF / Sticker Sheet), con sangrado, marcas de corte, imposición en hoja y revisión automática (Preflight) antes de exportar.
- Respaldo y restauración de proyectos (exportar/importar un archivo `.json` portable, incluyendo tus imágenes).
- Funciona 100% offline después de la descarga inicial. Sin cuenta, sin suscripción, sin telemetría.

**Limitaciones conocidas de esta versión:** ver `06-requisitos-y-limitaciones.md`.
