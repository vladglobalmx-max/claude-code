# Checklist Operativo — Módulo 4: Compras / Cadena de Suministro

## Requisición y segmentación
- [ ] Toda requisición tiene justificación de negocio documentada.
- [ ] Todo ítem recurrente tiene cuadrante Kraljic asignado.
- [ ] Ítems Estratégicos tienen plan de contingencia documentado.
- [ ] Ítems de Cuello de botella tienen proveedor alterno identificado.

## Cotización y selección
- [ ] Compras estratégicas o nuevas tienen mínimo 3 cotizaciones (RFQ).
- [ ] Selección de proveedor justificada por TCO, no solo precio.

## Orden de compra y recepción
- [ ] Cero compras recibidas sin orden de compra (PO) previa.
- [ ] Toda recepción confirmada por el área solicitante contra la PO.

## Pago
- [ ] Ninguna factura pagada sin control de tres vías completo.
- [ ] Toda discrepancia de three-way match documentada con causa y resolución.
- [ ] Compras que exceden el umbral de autorización tienen aprobación del CFO.

## Evaluación de proveedores
- [ ] Todo proveedor activo tiene scorecard vigente (últimos 12 meses).
- [ ] Proveedores "En observación" tienen plan de seguimiento documentado.

## Gobierno documental (heredado del Módulo 0)
- [ ] Este módulo y sus SOPs cumplen las 15 secciones del estándar.
- [ ] Validado por el Director de Compras.
- [ ] Fecha de próxima revisión registrada (≤6 meses).
