# Cómo empezar — THÖREN Sticker Builder

## Cómo abrir THÖREN

1. Descomprime el archivo ZIP que descargaste de Gumroad en cualquier carpeta de tu computadora.
2. Abre el launcher correspondiente a tu sistema:
   - **Windows**: doble clic en `ABRIR-THOREN-WINDOWS.bat`.
   - **macOS/Linux**: doble clic en `ABRIR-THOREN-MAC-LINUX.command` (en macOS, la primera vez puede que necesites hacer clic derecho → "Abrir" para permitirlo, ya que no está firmado por Apple).
3. Se abrirá una ventana de terminal/consola (necesaria para que THÖREN funcione — no la cierres mientras usas la aplicación) y tu navegador abrirá THÖREN automáticamente.
4. Para salir, simplemente cierra la ventana de terminal/consola cuando termines.

**¿Por qué no puedo simplemente abrir `index.html` haciendo doble clic?** Los navegadores modernos bloquean por seguridad el código que usa THÖREN cuando se abre directamente como archivo — es una restricción del navegador, no de THÖREN. El launcher soluciona esto sirviendo la aplicación como lo haría un sitio web real, pero completamente en tu propia computadora, sin conexión a internet.

## Cómo crear un proyecto

Al abrir THÖREN, llegas a "Mis proyectos". Haz clic en **"Nuevo proyecto"**:
- Elige una plantilla ya lista (tamaños comunes de sticker), o
- Elige "Tamaño personalizado" para definir tu propio ancho/alto.

Tu proyecto se abre inmediatamente en el editor, listo para diseñar.

## Cómo guardar y recuperar

**No necesitas guardar manualmente** — THÖREN guarda tu trabajo automáticamente mientras editas (verás el indicador "Guardando…" / "Guardado" en la barra superior). También puedes presionar `Ctrl+S` (Windows/Linux) o `Cmd+S` (Mac) para forzar un guardado inmediato.

Si THÖREN se cierra inesperadamente (se va la luz, se cierra el navegador por error) antes de que el guardado automático alcance a correr, la próxima vez que abras THÖREN verás un aviso ofreciéndote recuperar esos cambios — puedes aceptarlos o descartarlos.

Para volver a un proyecto ya guardado: en "Mis proyectos", haz clic en su miniatura o en "Abrir".
